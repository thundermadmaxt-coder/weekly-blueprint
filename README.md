## Important after updating
1. Upload these files to the repository root.
2. Wait for GitHub Pages to redeploy.
3. On Android, remove the old installed shortcut/app.
4. In Chrome, clear site data for the old app if needed.
5. Open the live URL again and reinstall from Chrome.

The checklist data is stored locally in the browser on each device.
